# Comment export by Combly

**Comment export, comment search and a giveaway winner picker for YouTube, TikTok and Instagram posts.**

This agent skill tells an agent how to use the Combly MCP server: load a post's comments, search them for what viewers ask or say, export comments to CSV, and use the comment picker to draw fair giveaway winners with a public winner page.

[Website](https://commentexport.app) · [MCP & API docs](https://commentexport.app/developers) · [MCP repository](https://github.com/commentexport/mcp-server)

## When to use it

> What are people asking under this YouTube video? https://www.youtube.com/watch?v=…

> Pick 3 winners from this Instagram post. Comments must tag 2 friends; leave out @mybrand.

## Install

```sh
npx skills add commentexport/agent-skill
```
